This project focuses on analyzing customer churn data to identify key factors influencing customer retention and attrition. Using Python-based data analysis and visualization techniques, the project uncovers patterns that help businesses reduce churn and improve customer satisfaction.

Key Highlights:

Performed data cleaning and exploratory data analysis (EDA) using Pandas and NumPy.

Analyzed churn drivers such as tenure, contract type, monthly charges, and service usage.

Created insightful visualizations using Matplotlib and Seaborn to compare churn vs non-churn customers.

Generated actionable insights to support customer retention strategies and decision-making.

Tools & Technologies:
Python, Pandas, NumPy, Matplotlib, Seaborn
